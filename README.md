# KNN Binary Classification – Breast Cancer Prediction

## 📌 Project Overview
This project uses the **K-Nearest Neighbors (KNN)** Machine Learning algorithm to classify breast cancer tumors into two categories:

- **Benign (B):** Non-cancerous tumor.
- **Malignant (M):** Cancerous tumor.

The main objective is to build a classification model that predicts whether a tumor is benign or malignant based on the given medical features.

## 🎯 Objectives
- Understand the KNN classification algorithm.
- Perform data preprocessing and cleaning.
- Split the dataset into training and testing sets.
- Apply feature scaling using StandardScaler.
- Train the KNN classification model.
- Evaluate model performance using different metrics.

## ⚙️ Algorithm Used

**K-Nearest Neighbors (KNN)**

KNN is a supervised Machine Learning algorithm used for classification and regression. It predicts the class of a new data point based on the majority class of its nearest neighbors.

## 📊 Model Evaluation

- Classification Report
